# Dell XPS 13 9340 (Meteor Lake, IPU6) — step by step

Tested: Ubuntu 26.10, kernel 7.3.0-10-generic, BIOS 1.30.0, Secure Boot **off**.
Run commands from the repository root. Reboot when told to — **never reload camera drivers live**
(`modprobe -r ov02c10` panicked this kernel).

## 0. Check the starting point

```bash
sudo apt install v4l-utils libcamera-tools
scripts/check-cameras.sh
```

Expected before the fix: `ov02c10` bound behind "Intel IVSC CSI" but with **no `v4l-subdev` node**,
and `pending_async_subdevices` listing `HIMX1092`.

## 1. Kernel side

```bash
sudo apt install dkms linux-headers-generic linux-source-$(uname -r | cut -d- -f1)

# HM1092 IR sensor driver - fixes both cameras (reset-GPIO patch is required on this model)
sudo cp -r dkms/hm1092-dell /usr/src/hm1092-dell-1.1
sudo dkms install hm1092-dell/1.1

# IPU6 boot-time crash fix (runtime-PM NULL deref race seen ~1 in 2-5 boots)
dkms/prepare-source.sh ipu6-isys-pmguard /tmp/ipu6-isys-pmguard-1.0
sudo cp -r /tmp/ipu6-isys-pmguard-1.0 /usr/src/
sudo dkms install ipu6-isys-pmguard/1.0

# Keep camera drivers out of the initramfs (firmware isn't declared -> breaks after updates)
sudo cp config/xps13-9340/dracut/90-camera-not-in-initramfs.conf /etc/dracut.conf.d/
sudo update-initramfs -u
```

**Reboot.** `scripts/check-cameras.sh` should then show `hm1092` and `ov02c10` sub-device nodes,
nothing pending, and `cam -l` listing `\_SB_.PC00.LNK0` (IR) and `\_SB_.PC00.LNK1` (RGB).

> **RGB-only alternative** (no IR driver): instead of `hm1092-dell`, install `ipu-bridge-noir`
> (`dkms/prepare-source.sh ipu-bridge-noir ...`). Do **not** install both.

## 2. Desktop (user config, no sudo)

```bash
mkdir -p ~/.config/wireplumber/wireplumber.conf.d ~/.config/systemd/user/wireplumber.service.d
cp config/common/wireplumber/50-hide-ipu-raw.conf       ~/.config/wireplumber/wireplumber.conf.d/
cp config/xps13-9340/wireplumber/51-camera-names.conf   ~/.config/wireplumber/wireplumber.conf.d/
cp config/common/systemd-user/wait-for-camera.conf      ~/.config/systemd/user/wireplumber.service.d/
systemctl --user daemon-reload && systemctl --user restart wireplumber
```

Note the camera IDs on this model contain `PC00` (`\_SB_.PC00.LNK1`), unlike the 9350.

## 3. Optional

- **Gaze** face unlock: [patches/gaze/README.md](../patches/gaze/README.md), camera settings in
  [config/xps13-9340/gaze-cameras.toml](../config/xps13-9340/gaze-cameras.toml).
- **Chrome/Meet** and **Zoom**: developed on the 9350 (see [xps13-9350.md](xps13-9350.md)); they
  should apply here with `\_SB_.PC00.LNK1` as the camera name, but were **not tested on the 9340**.

## Undo

| Piece | Undo |
|---|---|
| HM1092 driver | `sudo dkms remove hm1092-dell/1.1 --all` + reboot |
| Crash fix | `sudo dkms remove ipu6-isys-pmguard/1.0 --all` + reboot |
| dracut file | `sudo rm /etc/dracut.conf.d/90-camera-not-in-initramfs.conf && sudo update-initramfs -u` |
| WirePlumber files | delete them, restart WirePlumber |
